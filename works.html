ロゴ / 名刺 / WEB

制作概要

自分の名前の頭文字「M」と「A」を起点に、2文字が一本の線として連続的につながる形を探りました。形そのものと余白が最もよく見える構成を目指しています。

制作年2018–2026担当デザイン制作物ロゴ / 名刺 / WEB使用ツールIllustrator / Photoshop

形ができるまで

名前の頭文字「M」と「A」を起点に、二つの形をつなぎ、角を曲線へ置き換えながら現在のロゴマークへ整えました。

ロゴの仕様

用途に応じた使用を想定し、ロゴマーク単体、名前との組み合わせ、モノクロとカラーの展開を設定しました。

ADJAS

ロゴ / 名刺 / WEB

制作概要

社名の「A」「D」と新緑をモチーフに、環境への取り組みを象徴する形を検討しました。特徴がありながら、幅広い用途で使えるシンプルな企業ロゴです。

制作年2018担当デザイン / コーディング制作物ロゴ / 名刺 / WEB使用ツールIllustrator / Photoshop / HTML / CSS / JavaScript

形ができるまで

ADJASの文字からA・Dの構造を抽出し、色と線を検討しながら、環境への取り組みを象徴する完成形へ整えました。

ロゴの仕様

完成したロゴを、マーク、ロゴタイプ、モノクロ、ブランドカラーへ展開しました。
